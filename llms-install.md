# Install the SecLens.ONE MCP server

Add this anonymous Streamable HTTP server. No account and no `Authorization` header.

`https://seclens.one/mcp`

Tools are `get_result`, `assess_domain`, and `get_summary`.

```json
{
  "mcpServers": {
    "seclens": {
      "type": "http",
      "url": "https://seclens.one/mcp"
    }
  }
}
```
